# Emergency Response System

A real-time emergency management prototype designed to enable fast, coordinated, and intelligent response in hospitality environments.

---

## Overview

Emergency situations in hospitality settings often suffer from delayed and fragmented communication between guests, staff, and management.

This project presents a unified system that allows users to report emergencies instantly, automatically classifies incidents based on severity, and ensures efficient coordination across all stakeholders.

The goal is to reduce response time and improve safety through structured, real-time communication.

---

## Features

### Emergency Reporting
- Text-based input  
- Voice-based input (speech-to-text concept)

### Smart Classification
- Detects type: Fire / Medical / Security  
- Assigns severity: Critical / Medium / Low  

### Real-Time Alert Pipeline
- Reported → Assigned → Resolved  

### Role-Based System (Prototype)
- User (report incidents)  
- Staff (handle alerts)  
- Admin (monitor system)  

### Dashboard Overview
- Visual status tracking  
- Severity-based prioritization  

---

## Prototype Scope

This is a demonstration prototype where all roles (User, Staff, Admin) are integrated into a single interface.

In a production-grade system, these would be separated into secure, role-based applications with authentication, real-time backend services, and scalable infrastructure.
